# Initial Release: `v0.1.0`

Introducing `pico-pydantic`, a robust integration layer that enforces **Runtime Type Safety** within your `pico-ioc` applications using **Pydantic V2**.

This library bridges the gap between Python's static type hints and runtime execution, allowing you to build defensive, self-validating service components without cluttering your business logic with manual checks.

## ✨ Key Features

  * **Declarative Validation**: Use the `@validate` decorator to mark methods that require input validation. The library uses an AOP Interceptor pattern to handle the rest transparently.
  * **Automatic Hydration**: It doesn't just validate; it **transforms**. Arguments annotated with Pydantic models receive fully hydrated instances, turning raw `dict` or JSON inputs into safe objects before your method ever runs.
  * **Complex Type Support**: Powered by Pydantic's `TypeAdapter`, it recursively handles and converts complex generic structures like `List[Item]`, `Optional[User]`, or `Union[Request, str]`.
  * **Smart Argument Binding**: Includes a robust binding strategy that correctly normalizes arguments for instance methods (`self`), class methods (`cls`), and keyword-only arguments, ensuring the validator always sees the complete picture.
  * **Clean Architecture**: Decouples validation concerns from domain logic. Your service methods remain pure and focused on business rules, trusting that their inputs are already valid contracts.

## Example

```python
from typing import List
from pydantic import BaseModel
from pico_ioc import component, init
from pico_pydantic import validate

# 1. Define your Data Contracts
class Order(BaseModel):
    id: int
    items: List[str]

# 2. Define your Service
@component
class OrderService:
    
    # 3. Decorate to enforce the contract
    @validate
    def process_batch(self, orders: List[Order]) -> int:
        # 'orders' is GUARANTEED to be a list of Order objects.
        # No manual validation or conversion needed here.
        return len(orders)

# 4. Initialize Container
container = init(modules=[__name__, "pico_pydantic"])

# 5. Execute
service = container.get(OrderService)

# Pass raw dicts -> Receive Objects
service.process_batch([
    {"id": 1, "items": ["apple"]}, 
    {"id": 2, "items": ["banana"]}
])
```
